## The entry

A one-line family scene, warm, funny and heartfelt: a mum who keeps Dad's
first burnt pancake in the freezer, labelled "Exhibit A", and the anniversary
ritual of thawing it for one bite.

`main.py` (stdlib only) writes the scene to the output path resolved from
`ENTRY_OUTPUT`, else `OUTPUT_DIR` / `MAKEFUN_OUTPUT_DIR`, else
`/output/entry.txt`, else the script's own directory.

Run it:

```sh
python3 main.py
```
